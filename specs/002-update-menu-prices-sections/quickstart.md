# Quickstart: Verifying Menu Updates

To verify the changes locally:

1. Ensure Flutter is configured for web.
2. Run the application:
   ```powershell
   flutter run -d chrome
   ```
3. Navigate to the Menu page.
4. Verify the following:
   - "Burgers" and "Hotdog Bun" categories are missing.
   - Price of "Shawarma Wrap" is ₱60.
   - Price of "Shawarma Quesadilla" is ₱75.
   - All promotional labels say "Buy 1 Take 1".
   - "Oreo Craze" items are visible in the "Extras" section priced at ₱65.
